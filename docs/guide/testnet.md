# Early access on testnet

During early access, Nexlm runs on the **Stellar testnet** — a copy of the Stellar network for testing.

## What that means

| | Testnet | Mainnet |
| --- | --- | --- |
| XLM value | None | Real |
| New wallets | Funded with 10,000 test XLM | Start empty |
| Explorer links | stellar.expert/explorer/**testnet** | stellar.expert/explorer/**public** |
| Resets | Stellar may reset testnet periodically | Never |

The **Wallet** page shows a **Testnet** badge and the Deposit panel shows a warning while you're on testnet.

## Please don't

- Send real XLM from an exchange to a testnet address — it won't arrive and can't be recovered.
- Send real Naira for testnet trades unless the early access programme asks you to test with a nominal amount.

## Why test on testnet?

Every escrow, release and refund works exactly as it will on mainnet, so you can learn the flow and help us find issues without risking funds.

## Moving to mainnet

Testnet accounts won't carry over. When Nexlm launches on mainnet, you'll create a fresh wallet; your login may be migrated, and we'll announce the details beforehand.
