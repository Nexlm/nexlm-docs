# Verify your identity (KYC)

Everyone trading Naira on Nexlm verifies their identity with a **BVN** or **NIN**.

## Submit your details

Go to **Verify identity** (from the banner or **Settings**) and enter:

| Field | Notes |
| --- | --- |
| ID type | BVN or NIN |
| ID number | 11 digits |
| First and last name | Exactly as on the ID record |
| Date of birth | You must be at least 18 |

## Outcomes

| Status | Meaning |
| --- | --- |
| **Verified** | Your details matched. You can trade. |
| **Under review** | Your submission is queued for manual review by the Nexlm team. |
| **Rejected** | The details didn't match. You can correct them and submit again. |

## What Nexlm stores

- The ID type and **last four digits**
- The name you submitted
- A one-way fingerprint of the ID, used to stop the same ID being used on another account

Your full BVN or NIN is **never stored**.

## Common problems

- **"This ID is already linked to another Nexlm account"** — each ID can back only one account. Contact support if this is wrong.
- **Rejected repeatedly** — check name order and spelling, try the other ID type, and confirm your date of birth on the record.
