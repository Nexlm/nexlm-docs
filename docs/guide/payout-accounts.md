# Add payout accounts

Payout accounts are where buyers send your Naira when you sell XLM. Add them in **Settings → Payout accounts**.

## Supported methods

| Method | Fields |
| --- | --- |
| Bank Transfer | Bank name, account name, 10-digit account number |
| OPay | Account name, 10-digit account number |
| PalmPay | Account name, 10-digit account number |
| Kuda | Account name, 10-digit account number |
| Moniepoint | Account name, 10-digit account number |

You can save up to **10** payout accounts. Saving the same method and number twice is rejected.

## How they're used

- To **post a sell order**, you need a saved account for every payment method the order accepts.
- To **sell into a buy order**, you need an account for the payment method you pick.
- In a trade, the buyer sees the seller's account for the trade's payment method.

::: warning Use accounts in your own name
The account name should match your verified identity. Mismatched names make buyers suspicious and cause disputes.
:::

## Removing an account

Tap the bin icon next to the account. Removing an account doesn't affect trades already in progress, but you won't be able to post new sell orders for that method until you add another.
