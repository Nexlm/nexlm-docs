# Glossary

| Term | Definition |
| --- | --- |
| **Account merge** | Stellar operation that sends an account's remaining balance to another account and deletes it. Used to close escrow. |
| **Base reserve** | 0.5 XLM unit used to compute Stellar minimum balances |
| **BVN** | Bank Verification Number — 11-digit identifier for Nigerian bank customers |
| **Completion rate** | Completed trades ÷ (completed + cancelled trades) |
| **Custodial wallet** | A wallet whose secret key is held (encrypted) by Nexlm |
| **Escrow account** | A Stellar account created per trade to hold the seller's XLM |
| **Friendbot** | Testnet service that funds new accounts with test XLM |
| **Horizon** | Stellar's REST API |
| **KYC** | Know Your Customer identity checks |
| **Kobo** | 1/100 of a Naira |
| **Maker / taker** | The user who posted an order / the user who opens a trade on it |
| **Master weight** | The signing weight of an account's own key; set to 0 on escrow accounts |
| **Memo** | Short note attached to a Stellar transaction |
| **NGN** | Nigerian Naira |
| **NIN** | National Identification Number issued by NIMC |
| **Payment window** | Time a buyer has to pay after escrow locks (15 minutes by default) |
| **Payout account** | Bank or wallet account where a seller receives Naira |
| **Platform key** | Nexlm's escrow co-signer (`PLATFORM_SECRET_KEY`) |
| **Reconciliation** | Settling a trade by checking what actually happened on-chain |
| **Stroop** | 0.0000001 XLM, the smallest unit |
| **Subentry** | A ledger entry owned by an account (signer, trustline, offer), each adding 0.5 XLM to its reserve |
| **Testnet** | Stellar's test network; XLM there has no value |
| **XLM** | Stellar Lumens, the native asset of Stellar |
