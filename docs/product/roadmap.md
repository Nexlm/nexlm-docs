# Roadmap

## Phase 1 — MVP ✅ built

| Feature | Status |
| --- | --- |
| Email registration, verification, password reset | ✅ |
| Custodial Stellar wallet, deposit (QR), withdraw, activity | ✅ |
| BVN/NIN verification (Smile ID + manual review) | ✅ |
| Buy/sell order board with filters and expiry | ✅ |
| Per-trade escrow lock, release, cancel, auto-refund | ✅ |
| Realtime trade chat with payment proof | ✅ |
| Completed trades, completion rate, verified badge | ✅ |
| Admin: overview, users, KYC review, trade monitoring | ✅ |
| Reconciliation of uncertain Stellar outcomes | ✅ |
| Phone OTP verification | ⏳ phone number stored, OTP not yet |

## Phase 2 — Trust & safety

- Dispute system: raise a dispute, admin review of chat and proof, admin release or refund
- Star ratings and short reviews after trades
- Two-factor authentication (authenticator apps)
- Email and push notifications for trade events
- Platform analytics charts for admins
- External Stellar wallet connections
- Mobile UI polish

## Phase 3 — Scale

- Partial order fills
- Live XLM/NGN market-rate pricing (fixed or % from market)
- Edit, extend and bulk-manage orders
- Leaderboards and referrals
- Cash / in-person trades for high-trust users
- Appeal window for dispute outcomes
- Native mobile app (React Native)

## Open questions

- Platform fee model, if any
- When to move from custodial to non-custodial by default
- Final KYC provider choice (Smile ID, Dojah or Prembly)
- Support for other Stellar assets such as USDC
- Final minimum and maximum trade sizes
- Admin-set reference rates
